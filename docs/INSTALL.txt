Four Rings - Mono 1.0.1

Four active ring slots in Tainted Grail: The Fall of Avalon.
Requires Windows x64 and a Mono game installation.
Tested on Mono 1.30.012. Other Mono builds are allowed but unverified.
Requires BepInEx 5 x64; tested with 5.4.23.6.
No other mod or mod manager is required. IL2CPP is unsupported.
Unknown fingerprints produce a warning. Structural checks remain enabled.

Tested TG.Main.dll SHA-256 (reference only):
57E9FBE5659B25539FDCF1A734F0C5CDE277FEDF36EEA6FEACB237855C69EE2A

INSTALL
1. Exit the game and back up your complete save profile.
2. Install BepInEx 5 x64 for the Mono branch.
3. Extract this ZIP beside Fall of Avalon.exe.
4. Check both DLL locations:
   BepInEx/patchers/FourRings/FourRings.Patcher.dll
   BepInEx/plugins/FourRings/FourRings.Plugin.dll
5. Start the game and open the equipment diagram.

UPDATE FROM 1.0.0
Exit the game and replace both DLLs. Slot identifiers and saves remain unchanged.

REMOVE
1. Keep both DLLs installed while loading your save.
2. Unequip both additional ring slots.
3. Create a manual save and exit completely.
4. Remove both Four Rings DLLs.
5. Load the cleaned manual save.

Older saves containing equipped additional slots still require the mod.
If initialization fails, avoid loading saves containing equipped additional slots.
Return to a compatible game build or a save cleaned before the update.
Original game DLLs remain unchanged; the patcher modifies memory only.
Physical gamepad input, merchant transactions, and combat-triggered ring effects remain unverified.
Manual installation is verified. Vortex installation is unverified.
